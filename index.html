Document Corrector

Document Corrector は、Microsoft Word 上で研究文書や論文原稿の表記、書式、図表、参考文献などを 点検する Office アドインです。文書内の問題箇所を検出し、修正候補の確認、一括修正、 マーカーやコメントによる指摘の追加を行えます。

対応環境は Microsoft Word for Mac（Microsoft 365 版）です。

できること

書式25-30 °C→25–30 °C、-78℃→–78 °C、10mL→10 mL、Figure 1に→Figure 1 に、1H NMR→¹H NMR
フォントギリシャ文字の Symbol フォント、和文と欧文の組み合わせ、物理量のイタリック
図表キャプションのピリオドと配置、本文が引用していない図表、化合物番号の登場順
参考文献引用番号と句読点の前後、雑誌略称、誌名は斜体・巻も斜体

指摘はルールごとにまとまって表示され、［まとめて修正］で一括して直せます。 要否は 1 件ずつ確認でき、［無視］したものはいつでも戻せます。

原稿の中身を数える 3 つの一覧

  • 化合物 — 番号ごとの登場回数と、何ページの何段落にあるか。場所を押すとそこへ飛びます。1 回しか出てこない番号（＝同定データの抜け）が一目で分かります。
  • 文献 — 引用番号と、末尾の文献リストから拾った書誌。書誌の無い番号と引用されていない文献に印が付きます。
  • フォントを置換 — 使われている書体の一覧と、まとめて置換する操作。

伝え方は 2 通り

分類ごとの色でマーカーを塗るか、指摘文そのものをWord のコメントとして挿入するか。 片付けるボタンは「このアドインが付けたものだけ」と「文書のすべて」に分かれているので、 共著者の書き込みを巻き込む心配がありません。

使い方はアドインの中にあります

パネルを開くと、まず［使い方］が出ます。操作の手順と、消すボタンの 違いはそこに書いてあります。あとから読み直すときはリボンの［使い方］です。

チェック項目の有効化・無効化

使用するチェック項目は、リボンの［設定］＞［点検するルール］タブで 個別に有効または無効にできます。

導入

設定ファイルをダウンロード

ダウンロードするのはこの 1 ファイルだけです（約 30 KB）。

  1. 上のファイルをダウンロードします。
  2. Finder で ⌘ + ⇧ + G を押し、次のフォルダを開きます。 
    ~/Library/Containers/com.microsoft.Word/Data/Documents/wef

    wef フォルダが無ければ、その名前で新規作成してください。

  3. ダウンロードした document-corrector.manifest.xml をこのフォルダに入れます。
  4. Word を ⌘ + Q で完全に終了し、起動し直します。
  5. 原稿を開き、［ホーム］→［アドイン］から Document Corrector を選びます。 リボンに ［Corrector］タブが現れます。

タブが出ないときは

Word を完全に終了してから起動し直したか確認してください。それでも出ない場合、 Word のバージョンが古い可能性があります（Mac 16.61 以降の Microsoft 365 版が必要です）。古い Word でも、［ホーム］→［アドイン］からパネルだけは開けます。

更新について

通常の更新は自動的に反映されます。再インストールが必要な場合のみ、このページでお知らせします。

プライバシー

  • アドインの画面とプログラムは、GitHub Pages から読み込まれます。
  • Word 文書の本文やコメントなどの内容が GitHub へ送信されることはありません。
  • 文書の解析と修正は、Word 内で実行されます。
  • 設定（チェック項目の有効／無効、マーカーの色）はお使いの Mac の中だけに保存されます。
  • 読み込みのため、オフラインでは動作しません。ネットワークに接続してお使いください。

不具合・要望

GitHub の Issues か、 研究室内で直接お知らせください。誤検出の報告は、その箇所の文が分かると直しやすいです。
