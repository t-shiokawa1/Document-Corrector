Document Corrector

研究室の「文章添削チェックリスト」のうち、機械的に判定できる項目を Word の中で点検する拡張機能です。 指摘にはチェックリストと同じ色のマーカーを塗るので、手で添削した原稿と見た目が揃います。

できること

チェックリストの自動点検（41 項目）

分類例
文章の可読性更に→さらに、〜を有する→〜をもつ、長すぎる文、表記のゆらぎ、句読点の混在
書式25-30 °C→25–30 °C、-78℃→–78 °C、10mL→10 mL、Figure 1に→Figure 1 に、1H NMR→¹H NMR
フォントギリシャ文字の Symbol フォント、和文と欧文の組み合わせ、物理量のイタリック
図表キャプションのピリオドと配置、本文が引用していない図表、化合物番号の登場順
参考文献引用番号と句読点の前後、雑誌略称、誌名は斜体・巻も斜体

指摘はルールごとにまとまって表示され、［まとめて修正］で一括して直せます。 要否は 1 件ずつ確認でき、［無視］したものはいつでも戻せます。

原稿の中身を数える 3 つの一覧

  • 化合物 — 番号ごとの登場回数と、何ページの何段落にあるか。場所を押すとそこへ飛びます。1 回しか出てこない番号（＝同定データの抜け）が一目で分かります。
  • 文献 — 引用番号と、末尾の文献リストから拾った書誌。書誌の無い番号と引用されていない文献に印が付きます。
  • フォントを置換 — 使われている書体の一覧と、まとめて置換する操作。

伝え方は 2 通り

チェックリストの色でマーカーを塗るか、指摘文そのものをWord のコメントとして挿入するか。 片付けるボタンは「このアドインが付けたものだけ」と「文書のすべて」に分かれているので、 共著者の書き込みを巻き込む心配がありません。

導入

マニフェストをダウンロード

ダウンロードするのはこの 1 ファイルだけです（約 30 KB）。

Mac

  1. 上のファイルをダウンロードします。
  2. Finder で ⌘ + ⇧ + G を押し、次のフォルダを開きます。 
    ~/Library/Containers/com.microsoft.Word/Data/Documents/wef

    wef フォルダが無ければ、その名前で新規作成してください。

  3. ダウンロードした document-corrector.manifest.xml をこのフォルダに入れます。
  4. Word を ⌘ + Q で完全に終了し、起動し直します。
  5. 原稿を開き、［ホーム］→［アドイン］から Document Corrector を選びます。 リボンに ［Corrector］タブが現れます。

Windows

共有フォルダを信頼できるカタログとして登録する手順が必要です。 Microsoft の手順 に従ってマニフェストを登録してください。

タブが出ないときは

Word を完全に終了してから起動し直したか確認してください。それでも出ない場合、 Word のバージョンが古い可能性があります（Mac 16.61 以降 / Windows 2205 以降の Microsoft 365 版が必要です）。古い Word でも、［挿入］→［アドイン］からパネルだけは開けます。

更新について

ここが少し変わっているので、先に知っておいてください。

変わったものあなたの操作
点検ルール、判定の改善、パネルの表示不要。次に Word を開いたときには最新になっています
リボンのボタン（追加・削除・名前）このページからマニフェストを取り直して入れ直し

プログラム本体は毎回この場所から読み込まれるので、ルールの修正は黙って届きます。 入れ直しが要るときだけ、パネルの上部に「新しいバージョンがあります」と表示されます。 それが出るまでは何もしなくて構いません。

プライバシー

  • 文書の内容が外部に送信されることはありません。 点検はすべてお使いの Word の中で完結します。
  • プログラムの読み込みのため、Word はこのページと同じ場所（GitHub）へ接続します。文書の中身は含まれません。
  • 設定（ルールの入り切り、マーカーの色）はお使いの PC の中だけに保存されます。
  • そのためオフラインでは動作しません。ネットワークに接続してお使いください。

不具合・要望

GitHub の Issues か、 研究室内で直接お知らせください。誤検出の報告は、その箇所の文が分かると直しやすいです。
